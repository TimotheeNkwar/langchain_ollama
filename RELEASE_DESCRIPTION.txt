🎬 LangChain Ollama - Movie Search & AI Chat Application
=========================================================

VERSION 1.0.0 - Release Description

PROJECT OVERVIEW
================

LangChain Ollama is an intelligent movie search application that combines
the power of local language models (via Ollama) with LangChain to deliver
an advanced and conversational search experience.

KEY FEATURES
============

✅ Intelligent Movie Search
   - Semantic search across 50,000 TMDB movies
   - AI-powered intelligent suggestions
   - Advanced filtering by genre, year, and rating

✅ Integrated AI Chat
   - Conversational interface with AI
   - Personalized recommendations
   - Movie discussions

✅ Optimized Caching System
   - Redis for result caching
   - Improved performance for frequent queries
   - Intelligent cache management

✅ Robust API Backend
   - Complete REST API
   - LangChain integration
   - Multi-user support

✅ Modern Frontend
   - Responsive React interface
   - Elegant custom CSS design
   - Smooth user experience (Vite)

TECHNICAL ARCHITECTURE
======================

Backend:
  - Python 3.x
  - LangChain for LLM orchestration
  - Ollama for local models
  - Redis for caching
  - FastAPI for REST API

Frontend:
  - React.js
  - Vite (modern bundler)
  - Reusable components
  - Responsive CSS

Dataset:
  - TMDB 50,000 movies
  - Complete metadata

QUICK START
===========

1. Clone the repository:
   git clone https://github.com/TimotheeNkwar/langchain_ollama.git
   cd langchain_ollama

2. Install dependencies:
   pip install -r requirements.txt
   cd frontend && npm install

3. Configure Redis:
   - See REDIS_SETUP_NOTE.md for instructions

4. Run the application:
   python run_api.py
   cd frontend && npm run dev
